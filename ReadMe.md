# Customer Retention & Cohort LTV Analysis

![Customer Retention & Cohort LTV Dashboard](dashboard_preview.png)

## Executive Summary
This end-to-end data analytics project evaluates customer retention behaviors, monthly cohort drop-off rates, and cumulative Lifetime Value (LTV) growth. Designed for executive decision-making, the report translates raw transactional data into actionable growth metrics to help optimize customer acquisition strategies and maximize long-term customer value.

---

## Key Business Insights & KPIs
* **Active Customer Base:** Standardized filtering highlights active customer counts alongside overall retention benchmarks across historical acquisition cohorts.
* **Cohort Retention Dynamics:** The integrated matrix heatmap tracks user retention formatted by month (`yyyy-MM`), revealing critical drop-off points between initial purchase and subsequent months.
* **Cumulative Revenue Growth:** Line chart visualizations track long-term revenue trajectories per cohort to identify high-performing customer segments over time.

---

## Technical Architecture & Tools
* **SQL:** Data extraction, cleaning, date normalization, and base CTEs for cohort grouping.
* **Power BI Desktop:** Data modeling, dynamic DAX measures for retention percentages and running cumulative LTV, and custom formatting.
* **UI/UX Design:** Standardized typography (**Segoe UI**), structured left-aligned design hierarchy, dark slate executive color scheme (`#1E293B`), and high-contrast color-coded KPI indicators.
* **Version Control:** Git & GitHub tracking `.pbix` report versions, raw/processed SQL scripts, and image previews.
